# RAGE-Evo-I-Enhanced-GTA-V-Modding-Suite-for-3ds-Max
RAGE Evo is a heavily enhanced and expanded version of GIMS EVO by 3Doomer, bringing GTA V modding into one modern workflow inside 3ds Max. Import and export GTA V assets directly without switching between multiple tools. Models, collisions, materials, maps, interiors, lights, occluders, textures and animations are all handled in one place.
